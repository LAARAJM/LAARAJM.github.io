Projet CESI · Module Programmation orientée objet

Le Jeu de la Vie : une simulation bien construite


La simulation de John Conway : chaque cellule vit ou meurt selon ses voisines. Le défi : un code propre, découpé en modules et facile à faire évoluer.




  • C++
  • SFML
  • SOLID
  • Design patterns




Comment c'est construit

    

  • 3 couches bien séparées : le moteur, la logique et l'affichage.
    • 

  • Pattern État pour les cellules (vivante ou morte), sans longues suites de conditions.
    • 

  • Règles d'évolution rangées dans leur propre classe, faciles à remplacer.
    • 

  • Deux interfaces : une console qui enregistre chaque étape, et un affichage graphique en temps réel avec SFML.
    • 



Les extras

    

  • Grille torique : les bords sont reliés, comme dans Pac-Man. Ce qui sort à droite revient à gauche.
    • 

  • Lecture d'un fichier de départ et sauvegarde de chaque état.
    • 

  • Arrêt automatique quand la grille ne bouge plus.
    • 



Le calcul des voisins tient en une ligne, sans aucun « if » :

(coordonnée + taille) % taille








Projet CESI · Module Systèmes embarqués

3W : une station météo embarquée pour les navires


Un prototype de station météo pour aider à prévoir les cyclones. Elle mesure le temps, affiche les données à l'équipage et les enregistre sur une carte SD.










Fonctionnement normal : toutes les mesures sont prises et enregistrées sur la carte SD à intervalle régulier.


  • Arduino
  • ATmega328
  • I2C
  • SPI
  • UART
  • GPS




Le matériel

    

  • Microcontrôleur AVR ATmega328, sur une carte Arduino.
    • 

  • Capteurs : pression, température et humidité (I2C), GPS (UART), luminosité (analogique).
    • 

  • Carte SD (SPI) pour garder l'historique, horloge RTC (I2C) pour la date et l'heure.
    • 

  • Une LED de couleur et 2 boutons pour piloter la station.
    • 



Pensée pour l'équipage

    

  • Simple à utiliser par un membre d'équipage, avec une documentation utilisateur.
    • 

  • La couleur de la LED indique le mode en un coup d'œil.
    • 

  • Un mode économique pour faire durer la batterie en mer.
    • 

  • Un mode maintenance pour retirer la carte SD sans perdre de données.
    •

  3. Reprise
  4. →
  5. Assurance
  6. →
  7. Paiement
  8. →
  9. Résumé

  • Windows Forms
  • SQL Server

  • Visual Studio




Ce que gère l'application

    •

  • Reprise ou vente de la voiture du client, avec une estimation automatique de sa valeur.
